F411 Future Watch Architecture

这不是当前模拟器代码的复制图，也不是 T-Watch 参考板路线图。 它是一张 C-first 的未来骨架：先把层与层之间的关系想清楚，再慢慢填入真实代码。

1. 总体分层图

从硬件事实到 UI 绘制，每一层只做自己的事。

文本流：Board/Driver -> Platform Port -> Services -> ModelStore/EventQueue -> Coordinator -> Screens -> UI Adapter。

2. 输入流图

按键、触摸、旋钮先变成语义输入，再影响页面。

文本流：Button/Touch -> Driver -> Input Service -> fixed input event -> Coordinator -> Screen。

3. 传感器 / 电源数据流图

真实硬件样本先稳定成模型快照，再通知上层。

文本流：Battery/IMU sample -> Domain Service -> ModelStore snapshot + EventQueue event -> Coordinator/Screen。

4. 页面 / 屏幕切换流图

业务决策和显示执行分开，Screen Manager 只执行动作。

文本流：Event + Model -> Coordinator -> ui_action_t -> Screen Manager -> Home/Launcher/Settings -> UI Adapter。
