模型更新到 UI 刷新

sequenceDiagram
    participant Source as Hardware or Fake Source
    participant Service as Service
    participant Core as watch_core ModelStore
    participant Snapshot as UiModelSnapshot
    participant Adapter as UI Adapter
    participant Subject as LVGL Subject
    participant Screen as Generated Screen

    Source->>Service: sample/update
    Service->>Core: typed model update
    Core->>Snapshot: build read-only snapshot
    Snapshot->>Adapter: publish snapshot
    Adapter->>Subject: set UI binding values
    Subject->>Screen: refresh generated widgets

卡片点击到页面切换

sequenceDiagram
    participant Card as Health Card XML/LVGL
    participant Adapter as UI Adapter
    participant Queue as watch_core EventQueue
    participant Coord as Coordinator
    participant Intent as PageIntent
    participant ScreenApi as Generated Screen API

    Card->>Adapter: LV_EVENT_CLICKED with feature id
    Adapter->>Queue: push UiEvent
    Queue->>Coord: dispatch event
    Coord->>Intent: open placeholder detail
    Intent->>Adapter: request screen transition
    Adapter->>ScreenApi: create/load generated screen
